# 🎬 IMDB Movie Review Sentiment Analysis

## 📖 Overview
This project focuses on cleaning and preprocessing the **IMDB Movie Reviews Dataset** for **Sentiment Analysis**.  
It is part of my **Data Science & NLP learning journey**, where I explore text cleaning, tokenization, stemming, and lemmatization techniques.

---

## 🧠 Objectives
- Clean and preprocess raw text reviews  
- Handle emojis, chat words, and spelling errors  
- Perform tokenization, stemming, and lemmatization  
- Prepare clean text data for sentiment analysis models  

---

## 🛠️ Tools & Libraries
- **Python**  
- **Pandas** – for data manipulation  
- **NLTK** – for tokenization, stopwords, and lemmatization  
- **TextBlob** – for spelling correction  
- **Emoji** – for emoji handling  
- **Regular Expressions (re)** – for text pattern cleaning  

---

## 🧹 Data Cleaning Steps
1. Convert all reviews to lowercase  
2. Remove HTML tags and URLs  
3. Remove punctuations and chatwords  
4. Correct spelling mistakes  
5. Remove stopwords  
6. Replace or remove emojis  
7. Tokenize text into words  
8. Apply stemming and lemmatization  

---

## 📊 Dataset
- **Source:** IMDB Movie Reviews  
- **Columns:**  
  - `review` → movie review text  
  - `sentiment` → positive / negative  
- **Rows:** ~50,000 reviews
