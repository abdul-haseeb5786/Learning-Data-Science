# 📅 Day 1 — Pandas Series

## 📖 Overview
A **Series** in Pandas is a one-dimensional labeled array that can hold any data type — integers, strings, floats, etc.  
It’s similar to a column in an Excel sheet or a NumPy array with labels.

---

## ⚙️ Key Concepts
- Create Series using **lists**, **NumPy arrays**, or **dictionaries**  
- Access Series **attributes** and use **methods** like `head()`, `tail()`, `sort_values()`  
- Perform **indexing**, **slicing**, and **editing** operations  
- Apply **mathematical** and **statistical** functions  
- Handle **missing values** using `dropna()` and `fillna()`
