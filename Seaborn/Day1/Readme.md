# 📅 Day 1 Overview — Seaborn Data Visualization

Welcome to **Day 1** of our Seaborn visualization journey!  
Today we learned how to use Seaborn for statistical visualizations and how it differs from Matplotlib.

---

## 🎯 Day 1 Learning Objectives
- Understand what Seaborn is  
- Learn difference between **figure-level** and **axes-level** plots  
- Use relational, distribution, and categorical plots  
- Practice FacetGrid and PairGrid for advanced multi-plot visualizations  
- Load built-in datasets like `tips` & `iris`

---

## 📌 What We Learned Today

### ✅ **1. Seaborn Basics**
- Importing Seaborn  
- Loading built-in datasets  
- Understanding plot categories  
- Using hue, style, and size for multivariate analysis  

---

### ✅ **2. Relational Plots**
These plots help analyze how one numerical variable changes with another.

We covered:
- Scatterplots  
- Lineplots  
- Figure-level `relplot`
- Multi-country comparison (Pakistan, Germany, Brazil)
- Facet relational plots using `row` and `col`

---

### ✅ **3. Distribution Plots**
Used for understanding data distribution and shape.

We practiced:
- Histograms (`histplot`)
- Displots (`displot`)
- KDE plots (`kdeplot`)
- Distribution with hue groups  
- Bins and element styling  

---

### ✅ **4. Categorical Plots**
Used for comparing numeric values across categories.

We learned:
- stripplot  
- swarmplot  
- boxplot  
- violinplot  
- barplot  
- countplot  
- catplot (figure-level with faceting)

---

### ✅ **5. Multi-Plotting**
Using Seaborn to create automatic grids of charts:

- `FacetGrid`
- Mapping plots using `g.map()`
- Multi-category comparison using rows and columns

---

### ✅ **6. Pairwise Visualizations**
Exploring relationships among all numeric columns at once.

We used:
- `pairplot`  
- `PairGrid`  
- Diagonal plots (boxplot)  
- Off-diagonal scatterplots  

---

## 🧠 Summary
Day 1 focused on mastering:
- Core Seaborn visualization techniques  
- Understanding plot categories  
- Learning figure-level vs axes-level plots  
- Building multi-dimensional analytics using hue, row, col, style, size  
- Exploring datasets like Tips, Iris, and Gapminder

By the end of Day 1, we had a solid understanding of Seaborn’s fundamentals and statistical plotting capabilities.
